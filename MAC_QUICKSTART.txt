📋 PREREQUISITES:
  ☐ Homebrew installed
  ☐ Node.js installed (brew install node)
  ☐ Conda installed (brew install --cask miniconda)

🚀 ONE-TIME SETUP (5 minutes):

  1. Run setup:
     ./setup_mac.sh

  2. Add API keys to .env file:
     nano .env
     (Add GOOGLE_MAPS_API_KEY, AMADEUS_API_KEY, AMADEUS_API_SECRET)

  3. Done!

▶️  DAILY USAGE (2 seconds):

  ./start.sh

  Then open: http://localhost:3000

⏹️  STOP:

  Press Ctrl+C in the terminal

🆘 TROUBLESHOOTING:

  "conda not found"
  → brew install --cask miniconda
  → conda init zsh
  → Restart terminal

  "npm not found"
  → brew install node

  Can't connect to server
  → Make sure ./start.sh is running
  → Check that both terminals show "Server started"

  No search results
  → Check API keys in .env file
  → Verify APIs are enabled in Google Cloud Console
